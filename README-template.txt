Bug Report — How to view

1. Extract this zip file first (right-click → Extract All, or your OS's
   equivalent). Opening viewer.html directly from inside the zip won't
   work — the video won't load, because browsers can't reach into a zip
   archive to find sibling files.

2. Once extracted, open viewer.html in your browser. Click any entry in
   the list on the right to jump the video to that exact moment.

Files in this report:
- viewer.html   → open this one
- recording.webm → the screen recording (also viewable on its own)
- logs.json     → raw captured console errors and failed network requests
